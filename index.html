    Install

    // standard Fabric install

    1. Install Fabric Loader for 1.21.11.
      Use the Fabric installer or your launcher of choice (Prism, the official launcher profile, etc.).
    2. Download the mod jar.
      The mod itself isn’t published yet. The button below currently links to Fabric API, a dependency the mod will need — not the mod.
    3. Drop it in your mods folder.
      Add any required dependencies the Modrinth page lists, then launch the Fabric profile.

    Dependencies (for example Fabric API) are not confirmed here. Check the mod's fabric.mod.json and list them.
